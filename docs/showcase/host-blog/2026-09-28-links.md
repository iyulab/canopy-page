# Links that find their way back

A link that breaks when its target is renamed teaches you not to link.

## Names, not places

Lumenfold resolves a link by the note's name, so moving a note into another folder changes
nothing a reader sees.

## Both directions

Every link is also a backlink: the note you linked to knows you did.
