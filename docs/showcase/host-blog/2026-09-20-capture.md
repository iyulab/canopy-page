# Capture first, sort later

A note that has to be filed before it is written is a note that does not get written.

## The cost of a folder

Every choice made at the moment of capture is a reason not to capture. Lumenfold takes the text
and nothing else.

## Sorting on the way back

The second time you open a note is the first time you know what it is about. That is when
Lumenfold offers a place for it.
