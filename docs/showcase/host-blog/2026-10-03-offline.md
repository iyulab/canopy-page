# Working offline, on purpose

Lumenfold writes to your disk before it does anything else, so a train tunnel is not an event.

## What syncs, and when

Changes travel when there is a network and wait when there is not. Nothing asks you to retry.

## What does not

Search, links and history run on the copy you already have.
