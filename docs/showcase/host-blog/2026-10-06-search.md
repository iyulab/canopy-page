# Search without a server

Lumenfold searches the copy of your notes it already has. There is no index to wait for on a
server, and nothing to lose when the network goes.

## What it matches

Titles first, then headings, then the text — so the note you named is the one you find.

## What it leaves out

Notes you archived stay out of the results until you ask for them.
