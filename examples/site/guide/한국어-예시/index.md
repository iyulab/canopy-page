# 한국어 예시

This page's directory is named 한국어-예시 — Korean for "Korean example." Nothing about it is
special beyond that name: it exists because [the previous page](../localizing.md) needed something
real to link to, to prove non-ASCII directory names resolve rather than just describe that they do.

If you are reading this, the link worked: canopy percent-encoded 한국어-예시 correctly in every
`href` that points here — the sidebar, the page you came from, the browser's address bar — and
canopy-page published the file at a path with that name intact.
