# Release notes

Newest first. The order is not written anywhere — the settings file asks this section for
`"order": "desc"` and the filenames do the rest.

Each note is dated in its frontmatter, so its date shows under its title, and the section sets
`"feed": true`: subscribe to `release-notes/feed.xml` in a feed reader to hear about the next one.

The list below is not written here either: `listing: true` in this page's frontmatter asks for
the pages it fronts, each with the date and summary the note gives itself.

This page also names the section: the sidebar reads "Release notes" rather than
`release-notes`, because this is the index page of that directory and it opens with a heading.
