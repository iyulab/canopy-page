# August 2026

## Pages are named by their own headings

A page with no `title:` line is now called by the heading it opens with rather than by its
filename, and that one name reaches the sidebar, the browser tab, and every backlink pointing at
it. A directory's index page names the directory too — which is why the sidebar entry above reads
"Release notes" while the folder is called `release-notes`.

The order is `frontmatter title → first heading → filename`. See
[Writing pages](../guide/writing/index.md).

## Percent-encoded links resolve

`[x](a%20b/note.md)` now addresses the same document as `[x](<a b/note.md>)`. Editors write the
first form on their own whenever a path contains a space, so any site with a space in a directory
name was affected.

## Settings unchanged

Nothing in [the settings file](../reference/settings.md) changed. A site built with the previous
release builds with this one — labels in the sidebar may read differently, which is the point.
