# September 28, 2026

## The front page comes first

On a site with no `sections` in `settings.json`, the root `index.md` used to be sorted in with
every other top-level page — after all the folders — so it sat at the bottom of the sidebar and
the previous/next links ended on it. It is now the first sidebar entry and the start of the
reading order: the front page has a "next" and no "previous", and the first page after it points
back to it. Sites that list `sections` already put the front page first; the two now agree.

## `--help` and `--version`

`canopy-page --help` (or `-h`, also after a command, as in `canopy-page build --help`) prints
the usage text and exits successfully, and `canopy-page --version` prints the installed version.
Both used to print the usage followed by an error and exit with a failure code.

## `check` asks the renderer what ships

`check` and `build` now work from one list of files: the one the renderer itself would publish.
Before, `check` worked it out separately, and it had fallen behind — hidden files such as `.env`
or `.gitignore` are never published, but `check` still counted them. An
[`exclude`](../reference/settings.md#top-level-fields) pattern that matches nothing is still
reported by name.
